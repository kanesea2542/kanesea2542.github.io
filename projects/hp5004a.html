HP 5004A Signature Analyzer

A VHDL implementation of the HP 5004A signature analyzer. A 16-bit linear-feedback shift register compacts serial input data into repeatable hexadecimal signatures for hardware fault analysis.

02 / Implementation

Modular RTL design

Sampling and signature generation

Edge-selection logic samples the start, stop, and clock inputs. Start/stop gate-generation state machines control the measurement window, while the 16-bit LFSR accumulates the serial data signature.

Capture and display

An output buffer captures the signature for the multiplexed seven-segment display. VHDL testbenches and FPGA validation covered timing, state transitions, signature capture, and real-time display output.
